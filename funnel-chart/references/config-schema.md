# 漏斗配置（JSON）字段说明

只给 `stages` 就能出图，其余字段都有默认值。

## 最小可用配置

```json
{
  "title": "新用户激活漏斗",
  "badge": "2026-09-22",
  "stages": [
    {"name": "安装", "count": 128400},
    {"name": "注册", "count": 41200},
    {"name": "首投", "count": 12800}
  ]
}
```

## 字段表

| 字段 | 默认 | 说明 |
|---|---|---|
| `title` | `转化漏斗` | 主标题 |
| `subtitle` | 逐级渗透口径说明 | 标题下副标题；给 `""` 可隐藏 |
| `badge` | 空 | 右上角数据日期角标（如 `2026-09-22`）；空则不画 |
| `badge_prefix` | `数据日期  ` | 角标前缀文案 |
| `out` | `funnel.png` | 输出文件名；相对路径按**配置文件所在目录**解析（skill 内的示例配置已改成同目录，复制到项目文件夹后按需调整） |
| `width` | `1772` | 画布宽（高度按层数自适应，无需指定） |
| `stages` | 必填 | 层数组，见下 |
| `colors` | 内置橙→蓝 8 色 | 全局配色，按下标取用 |
| `kpi_base_label` | `分析基数` | 第 2 张 KPI 卡的标题 |
| `kpi_base_sub` | `分析基数` | 第 1 层左侧副标签、第 2 张 KPI 卡的副标题（如 `进组且活跃`） |
| `kpi_e2e_sub` | 首层 → 末层 | 第 1 张 KPI 卡副标题 |
| `cum_label_prefix` | `对 DAU 累计` | 右侧累计渗透率前缀；非 DAU 漏斗可改 `对首层累计` / `对安装累计` |
| `foot_source_prefix` | `数据来源：` | 页脚第一段前缀 |
| `foot_source_text` | 各层人数串 | 页脚第一段内容（写清数据日期与来源） |
| `foot_source_suffix` | 渗透率算法说明 | 页脚第一段后缀 |
| `foot_note` | 版式说明 | 页脚第二段；写口径、替代基数、流失主因等 |

## `stages[]`

| 键 | 必填 | 说明 |
|---|---|---|
| `name` | ✅ | 环节名，如 `SPP点击渗透`；左侧与 KPI 卡都取这里 |
| `count` | ✅ | 人数（整数）；脚本据此算全部百分比 |
| `color` | — | `[r,g,b]`，覆盖该层配色 |
| `note` | — | 仅**末层**生效：补在右侧数据列最后一行（红字），用来写流失主因，如 `其中 74.2%（145 人）余额不足，无法受理` |

## 校验规则

- 少于 2 层直接报错。
- 某层人数大于上一层会报错并给出层号——这是漏斗口径问题，先和用户确认再画。
- 全部百分比（环节渗透率、对首层累计、漏损率、端到端）都由脚本现算；**不要**在配置里写百分比。
